# GoldenEye
Shiny app for analysis of percent cover on golden mussel settling surfaces.

## Version History:
v 1.0.0: HTML tool made using AI<br>
v 2.0.0: Modified for RShiny, corrected overestimating drawing tool calculations
         and refined experimental analysis variables to fit analysis.<br> 
v 2.0.1: Updated visual layout of app for Reclamation requirements, including
         editing colors to be colorblind friendly, adding logos, version#,
         and contact information.<br>
v 2.0.2: Updated tab tool to N-unlimited polygon, so wouldn't need to use obscure
         painting tool (pink drawing) to remove that space. Total area of tag
         will be corrected.<br>
## Disclaimer:
This app was designed for use in analysis of a specific experiment, and it may not be 
immediately usable for your experiment. Feel free to
take and modify for your own purposes.
